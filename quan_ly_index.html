🛠️ Công cụ chỉnh sửa Thư viện Boya

Cập nhật index.html theo 3 vùng: Giáo trình · Ngữ pháp · Bài kiểm tra — không cần sửa code tay.

Tải file index.html hiện tại

Công cụ đã có sẵn bản index.html gần nhất mà Claude tạo cho bạn. Nếu bạn đã tự sửa file ở nơi khác sau đó, hãy tải lên bản mới nhất để đồng bộ trước khi chỉnh sửa tiếp.

Giáo trình — Danh sách bài học

Sửa tên bài, pinyin và tên file .html cho từng bài. Thẻ sẽ tự chuyển sang "Có sẵn" khi có file.

Ngữ pháp — Chuyên đề riêng theo quyển

Mỗi chuyên đề ngữ pháp gồm tên hiển thị + tên file .html. Đây là nơi phù hợp cho các bài ôn tập ngữ pháp tổng hợp (không gắn với 5 bài cụ thể nào).

Bài kiểm tra — Theo từng đơn vị 5 bài

Mỗi đơn vị (5 bài học) có một bài kiểm tra riêng. Số đơn vị tự tính theo số bài đang có ở tab Giáo trình.

Xuất file index.html mới

Sau khi tải về, thay thế file index.html cũ trong thư mục dự án của bạn bằng file mới này (giữ nguyên các thư mục con boya1/, boya2/ như cũ).
Công cụ chạy hoàn toàn trong trình duyệt — không tải dữ liệu lên máy chủ nào.
