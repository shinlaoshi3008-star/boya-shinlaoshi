Cấu hình phòng thi Boya

Trang này tạo file cấu hình trên máy của thầy. Đây là công cụ thiết lập, không phải trang đăng nhập quản trị.

Để mọi học viên nghe cùng audio: tải MP3 lên thư mục audio của GitHub, rồi nhập đường dẫn ở trên. Chọn file trên máy trong bản xem thử chỉ phát trên máy đó, không tải file lên GitHub.

Tải file vừa tạo lên cùng thư mục với index.html và ghi đè config.js. Đóng trang cấu hình, mở lại trang thi để thử.
